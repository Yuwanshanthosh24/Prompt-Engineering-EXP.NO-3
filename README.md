EX.NO:3 Exploring the different types of prompts- Straightforward Prompts - Tabular Format Prompting - Missing Word Prompting - Preceding Question Prompting.

Aim: To write the prompts for the following prompt types for 2 different scenarios of Each type.

1.Straightforward Prompts

2.Tabular Format Prompting

3.Preceding Question Prompting

4.Missing Word Prompting

Explanation - Any one use case from Unit 5 or any 2 own use cases with the unit 2 Prompt type

PROCEDURE:

Step 1: Select Prompt Types 1.1 Identify different prompting techniques to be explored. 1.2 Choose Straightforward, Tabular, Preceding Question, and Missing Word prompts.

Step 2: Select Different Use Cases 2.1 Choose two different scenarios for each prompt type. 2.2 Ensure scenarios belong to different domains such as education, technology, science, and daily life.

Step 3: Create Straightforward Prompts

Scenario 1: Education

"Define Artificial Intelligence in one sentence."

Scenario 2: Technology

"List three advantages of cloud computing."

Step 4: Create Tabular Format Prompts

Scenario 1: Computer Science

"Compare Python and Java programming languages in a table with features, advantages, and applications."

Scenario 2: Electronics

"Provide a table listing five sensors, their functions, and applications."

Step 5: Create Preceding Question Prompts

Scenario 1: Environmental Science

"Why is water conservation important? Explain different methods used to conserve water."

Scenario 2: Health

"How does regular exercise improve health? Explain its benefits in simple terms."

Step 6: Create Missing Word Prompts

Scenario 1: Geography

"The largest ocean in the world is ____."

Scenario 2: Computer Science

"CPU stands for Central Processing ____."

Step 7: Analyze Prompt Structure 7.1 Observe how different prompt types guide AI responses. 7.2 Compare their structure and purpose.
